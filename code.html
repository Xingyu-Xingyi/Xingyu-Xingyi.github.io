判断 a 是不是 b 的子串 · 字符串哈希

先算 a 的哈希，再在 b 上滑窗口。命中之后还要逐字比一遍，不然撞了会误判。

bool sub(const string& a, const string& b) {
    if (a.size() > b.size()) return false;
    unsigned long long B = 131, t = 0, c = 0, pw = 1;
    for (char x : a) t = t * B + x;
    for (size_t i = 0; i < a.size(); ++i) {
        c = c * B + b[i];
        if (i) pw *= B;
    }
    if (c == t && b.compare(0, a.size(), a) == 0) return true;
    for (size_t i = a.size(); i < b.size(); ++i) {
        c -= (unsigned long long)b[i - a.size()] * pw;
        c = c * B + b[i];
        if (c == t && b.compare(i - a.size() + 1, a.size(), a) == 0) return true;
    }
    return false;
}

判断子串 · Z 算法

拼成 a + 分隔符 + b，谁的最长公共前缀等于 a 的长度就是出现位置。天生不会误判。

bool sub(const string& a, const string& b) {
    if (a.size() > b.size()) return false;
    string s = a + "\x01" + b;
    int n = s.size();
    vector<int> z(n);
    for (int i = 1, l = 0, r = 0; i < n; ++i) {
        if (i <= r) z[i] = min(r - i + 1, z[i - l]);
        while (i + z[i] < n && s[z[i]] == s[i + z[i]]) ++z[i];
        if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
    }
    for (int i = a.size() + 1; i < n; ++i)
        if (z[i] >= (int)a.size()) return true;
    return false;
}

上台阶 · 一次跨一、二、三级

跨 k 级的代价是 k 的平方，落地再付 costs 那一级。三个变量滚着走就是 O(n)，别写回扫。

long long climb(vector<int>& costs) {
    long long f0 = 0, f1 = 0, f2 = 0;   // d[i-3], d[i-2], d[i-1]
    for (int c : costs) {
        long long cur = min(min(f0 + 9, f1 + 4), f2 + 1) + c;
        f0 = f1; f1 = f2; f2 = cur;
    }
    return f2;
}

内存泄漏监视器

重载全局 new / delete，表里划不掉的留在退出时打印。表本身不能用 new 建，不然自己调自己。

void* operator new(std::size_t n) {
    void* p = std::malloc(n ? n : 1);
    if (!p) throw std::bad_alloc();
    record(p, n);          // 塞进静态表
    return p;
}
void operator delete(void* p) noexcept {
    forget(p);             // 从表里划掉，找不到就告警
    std::free(p);
}

163 的 IMAP 要先报 ID

不报客户端名，SELECT 会被判成 Unsafe Login。报完再选信箱。

imaplib.Commands["ID"] = ("NONAUTH", "AUTH", "SELECTED")
conn = imaplib.IMAP4_SSL("imap.163.com", 993)
conn.login(user, password)
conn._simple_command(
    "ID", '("name" "postbox" "version" "0.1" "vendor" "xingyi")'
)
conn._untagged_response("OK", [None], "ID")
conn.select("INBOX", readonly=True)
